### Single-Cycle RISC-V Processor | RTL Design

---

###  Overview

This directory contains the **SystemVerilog (RTL) source files** for the Single-Cycle RISC-V Processor. Each module represents a key functional component of the processor, working together to execute instructions in a single clock cycle.

### 🧩 Module Description

The design is organised into individual hardware modules covering:

- **ALU:** Arithmetic and logical operations.
- **Control Unit:** Instruction decoding and control signal generation.
- **Register File:** Register storage and data access.
- **Adder:** Address and arithmetic calculations.
- **Memory Units:** Instruction and data memory operations.
- **Program Counter:** Instruction sequencing and address management.

### 🛠️ Tools & Technologies

- **HDL:** SystemVerilog
- **Design & Simulation:** Xilinx Vivado
- **Architecture:** RISC-V (Single-Cycle)
